# Data source

The raw file `Telco-Customer-Churn.csv` is the public IBM Telco Customer Churn sample. IBM documents the sample as a fictional telco customer portfolio with a churn field indicating whether a customer departed within the last month and fields covering demographics, services, monthly charges, and tenure.

Stable download URL used by the build:

https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv

Reference pages:

- IBM documentation: https://www.ibm.com/docs/en/cognos-analytics/12.1.x?topic=samples-telco-customer-churn
- IBM GitHub source: https://github.com/IBM/telco-customer-churn-on-icp4d/blob/master/data/Telco-Customer-Churn.csv
- Kaggle listing: https://www.kaggle.com/datasets/blastchar/telco-customer-churn
